# structured_data.md Data Contract

> This document defines the canonical specification for `structured_data.md`.
> Generated by `vedic-calculator` or `vedic-reader`, and consumed by `vedic-core`, `vedic-career`, and `vedic-love`.

## Data Source Precedence

> **Primary Data Rule: Calculator > PDF / Screenshot / Text Extraction.**
>
> Whenever birth date, exact time, and location are complete, data computed by `vedic-calculator` serves as the
> canonical source of truth for `structured_data.md`. Manual chart extractions (PDF, image, text) are used solely
> for cross-verification and never override computational planetary positions, divisional charts, Dashas, SAV/BAV,
> house lords, dignities, Graha Drishti, special points, or transits.
>
> **Sole Exception - Shadbala**:
> - Always compute and retain calculator baseline values.
> - If PDF lacks Shadbala or extraction fails, write calculator baseline values directly.
> - If PDF contains verified Shadbala from the identical birth instant, compare line-by-line with calculator; display verified PDF values.
> - If discrepancies occur, notify user with note: `calc and PDF differ; currently using PDF values`.
> - If values match, annotate `PDF verification matched`.
> - After birth time rectification, historical PDF values become void; only newly calculated or recalculated values apply.
