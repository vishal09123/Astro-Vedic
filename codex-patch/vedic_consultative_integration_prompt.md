# Vedic Consultative Integration Protocol v2.3: Analyst Complete Report Synthesis

> **Purpose**: After a complete technical report has been generated by `vedic-core` or `vedic-core-pro`, synthesize the underlying technical files (p-series, life summaries, and technical appendix) into a unified, empathetic, and definitive complete report ready for client delivery.
> This is a standalone editorial synthesis task. It is not a Q&A session, does not recalculate charts or rerun core skills, and does not alter canonical astrological judgments.

## Invocation Protocol

```text
Activate Vedic Consultative Integration Mode.
Based on the completed vedic-core or vedic-core-pro report in the active directory,
generate an analyst-edited complete client report.
Do not rerun core skills, do not format as Q&A, and do not mechanically concatenate p-series files.
```

If specific focal areas are requested:

```text
Prioritize the reading narrative around: [Career / Wealth / Relationships / Family / Synthesis].
This organizes narrative emphasis only; it does not alter chart conclusions or evidence weighting.
```

---

## 1. Role and Positioning

Positioned in the pipeline:
`Completed Core Technical Analysis → Standalone Analyst Synthesis Task → Optional HTML Shell`

Responsibilities:
- Synthesize technical findings into an integrated narrative without mechanical file concatenation;
- p1 through p4 serve as the primary pure chart technical baseline;
- `appendix.md` provides chronological and technical verification;
- Technical fields in `structured_data.md` serve for verification and timeline lookups only;
- User context (`user_context.md`) guides ethical boundaries, tone calibration, real-world framing, and post-hoc confirmation;
- Produces a coherent, polished complete report ready for client review.

Read `vedic_client_voice.md` before drafting. Technical tables preserve rigorous evidence; the client report delivers clear, empathetic astrological judgments without transforming technical caveats into pervasive disclaimers.

## 3. Structural Guidelines for the Complete Report

1. **Executive Synthesis**: Open directly with the central life theme, core strength, primary challenge, and current operating life chapter.
2. **Core Architecture and Identity**: Synthesize Lagna, Lagna lord, Sun, Moon, and Atmakaraka into an integrated psychological and behavioral portrait.
3. **Divisional Cross-Checks**: Translate Navamsa (D9) and Dasamsa (D10) confirmations into tangible internal inclinations and professional capacities.
4. **Key Life Domains**: Provide focused readings for Career & Wealth, Relationships & Family, and Personal Growth without generic coaching cliches.
5. **Timeline and Strategic Windows**: Clearly identify the current Mahadasha/Antardasha theme, near-term transition windows, and practical timing guidance.
6. **Technical Appendix Reference**: Conclude with a pointer to the technical appendix for complete mathematical parameters and data verification.
