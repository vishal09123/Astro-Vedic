### Step 1: Adaptive Extraction

#### 1.1 Format Detection and Dual-Channel Extraction

| Input Type | Detection | Strategy |
|---|---|---|
| PDF | File extension `.pdf` | **Mandatory Dual-Channel** (see below) |
| Image / Screenshot | `.jpg`, `.png`, `.webp` | AI visual recognition |
| Text Paste | Text provided in prompt | Direct string parsing |
| Web Table | HTML / pasted markdown | Direct tabular parsing |

##### PDF Mandatory Dual-Channel Protocol (Never skip any step)

```
Channel A [Mandatory]: PyMuPDF Text Layer Extraction
  1. Extract full page text using PyMuPDF.
  2. Save text to temporary storage.
  3. Inspect extracted text.
  4. Parse planetary longitudes, degrees, Dasha tables, etc.
  5. ⚠️ Shadbala Extraction (JHora PDFs include Shadbala tables!):
     Search keywords: "Shadbala", "In rupas", "% Strength".
     Format: 5 values per planet: Shadbala (60ths) / In rupas / % Strength / Ishta / Kashta.
     Extract "In rupas" (column 2) and "% Strength" (column 3).
     If extracted successfully -> Label "PDF text extraction (JHora original)".
     If missing -> Label "PDF lacks Shadbala", degrade gracefully in Step 4.

Channel B [Mandatory]: AI Visual Inspection (D1 + D9 only)
  ⚠️ Do not open PDF in browser. Render page to PNG using PyMuPDF.
  1. Render chart pages to PNG (dpi=200).
  2. Inspect rendered PNG image.
  3. Identify chart style (South Indian vs North Indian).
  4. Read D1 and D9 placements visually.
  ⚠️ Channel B reads D1 and D9 only! Do not attempt visual reading of D10/D4/D5 from PDF.

Cross-Validation:
  - Channels A and B match -> High confidence.
  - Divergence -> Channel A (text layer with exact degrees) takes precedence;
    Channel B fills in missing D1 entries.
  - D9 Cross-Check: Formula calculation vs visual reading -> Formula takes precedence.
  - Channel A completely fails (scanned PDF) -> Rely on Channel B, confidence = Medium-Low.

Merging with Calc:
  - Calc output is canonical primary data; Channels A & B enter cross-validation log without overriding non-Shadbala fields.
  - For Shadbala: retain calc baseline, compare against valid PDF line-by-line.
  - Matching/existing PDF rows display PDF values; note discrepancies explicitly.
```
